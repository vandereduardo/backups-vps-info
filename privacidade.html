Política de privacidade

Esta política descreve o tratamento de dados pelo Backups VPS, ferramenta administrativa de cópias de segurança para ambientes autorizados.

1. Responsável e finalidade

O aplicativo é administrado por Vander Ferreira, com contato em vandereduardo@gmail.com. Sua finalidade é criar, verificar, recuperar e administrar a retenção de backups dos ambientes autorizados pelo responsável pelos dados.

2. Dados acessados

  • Conteúdo selecionado dos servidores autorizados, como arquivos e capturas consistentes de bancos de dados, conforme o escopo de backup definido para cada ambiente.
  • Arquivos de backup e metadados operacionais no Google Drive autorizados para o aplicativo: identificadores, nomes, tamanhos, horários e informações necessárias para conferência, recuperação e retenção.
  • Credenciais de autorização OAuth necessárias para executar a rotina sem pedir a senha do Google. Essas credenciais não são publicadas neste site.

O escopo solicitado é https://www.googleapis.com/auth/drive.file. Ele permite operar arquivos criados pelo aplicativo ou explicitamente autorizados para ele; não é uma solicitação de acesso irrestrito a todos os arquivos da conta.

3. Uso e limites

Os dados são usados somente para as funções de backup, recuperação, conferência, retenção e suporte autorizado. Não são vendidos nem utilizados para publicidade, criação de perfis ou treinamento de modelos de inteligência artificial.

O uso e a transferência de informações recebidas das APIs do Google devem observar a Política de Dados do Usuário dos Serviços de API do Google, inclusive suas exigências de uso limitado (Limited Use).

4. Armazenamento, proteção e provedores

O fluxo de backup previsto utiliza Restic para cifrar o conteúdo antes do envio ao Google Drive. Credenciais, chaves e permissões de acesso devem ficar restritas aos ambientes e operadores autorizados. A custódia das chaves é necessária para permitir a recuperação.

O Google Drive armazena os objetos de backup; os provedores dos servidores participam da execução e do armazenamento na origem. A hospedagem destas páginas é feita pelo GitHub Pages. Não compartilhamos o conteúdo dos backups com terceiros para finalidades diferentes das descritas nesta política. Acesso humano a dados de usuário deve ser limitado à autorização específica para suporte ou recuperação, ou às hipóteses legais aplicáveis.

5. Retenção e exclusão

A retenção é definida para cada repositório e ambiente. As rotinas podem remover cópias conforme essa configuração. A exclusão no aplicativo e a remoção definitiva pelo provedor podem ter etapas distintas, como lixeira e prazos do serviço.

O titular pode solicitar informações, correção de configuração, interrupção do tratamento ou exclusão pelo contato de suporte. A execução deve considerar sua identificação, autorização, obrigações aplicáveis e a preservação de dados que não lhe pertençam.

6. Revogação de acesso

A autorização pode ser revogada nas conexões da Conta Google. A revogação interrompe o acesso associado àquela autorização; não apaga automaticamente backups existentes. Antes de excluir cópias ou chaves, avalie o efeito sobre a recuperação.

7. Estas páginas

Este site não contém formulário de coleta, analytics, cookies próprios de aplicação ou código de autenticação. Ele não recebe o conteúdo dos backups. A infraestrutura de hospedagem pode tratar registros técnicos de acesso segundo a política de privacidade do GitHub.

8. Alterações e contato

Mudanças relevantes nas práticas devem ser refletidas nesta política e, quando necessário, em novo consentimento. Solicitações podem ser enviadas para vandereduardo@gmail.com.
